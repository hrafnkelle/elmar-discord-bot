# Elmar

Elmar helps Icelandic amateur radio operators choose callsigns and understand local geomagnetic activity.

## Language

**Callsign suffix**:
The letters after the digit in an Icelandic TF callsign. Availability checks treat a listed suffix as occupied across all digits.

**Leirvogur local K-index**:
A measure of geomagnetic disturbance at Leirvogur magnetic observatory (LRV), expressed on a scale from 0 to 9. It describes local conditions rather than the planetary Kp index.
_Avoid_: Icelandic Kp, global K

**Planetary Kp index**:
A geomagnetic activity index combining standardized observations from multiple observatories. It is a separate measurement from the Leirvogur local K-index.
_Avoid_: Leirvogur Kp

**Provisional local K-index**:
A local K value published using a near-real-time calculation procedure that may differ from the formal IAGA procedure. A provisional value is a reported observation, not a forecast.
